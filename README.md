# Avern — Nocturne landing page

A separate, lightweight landing page based on the visual direction of [Nocturne](https://github.com/ProPanda32/Nocturne). The original repository has not been changed.

This version removes the perfume bottle and the full top navigation. It keeps the atmospheric cavern setting, floating lights, and the fragrance and story sections.

Open `index.html` in a browser to preview the page. GitHub Pages can serve the repository root from the `main` branch.

The cavern background is referenced from the original repository's public image URL. The HTML and CSS are contained in this repository.
